# crono.io

Website for [Crono](https://github.com/crono-io/crono) — a scheduler and execution control plane for automated infrastructure tasks.

## Local preview

Install [www](https://crates.io/crates/www):

```sh
cargo install www
```

Clone the repository and start the server:

```sh
git clone https://github.com/crono-io/crono.io.git
cd crono.io
www
```

Then open `http://127.0.0.1:8000` in your browser.
