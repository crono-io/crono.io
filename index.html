What is Crono

A scheduler and execution control plane for automated infrastructure tasks.

Scheduler & control plane

Organize Jobs, Targets, Schedules, and Workflows in Namespaces and Queues. Each Run snapshots inputs immutably at creation.

Clear reliability model

Durable intent, at-least-once dispatch, and idempotent logical processing. Ambiguous lease losses become unknown instead of guessing.

Kubernetes & host execution

Run the API and web UI in Kubernetes via official Helm charts, and run static crono-worker binaries near your systems.

Why it’s different

PostgreSQL as source of truth, NATS JetStream for dispatch.

01 · Authority

PostgreSQL as source of truth

Catalogs, next_run_at cursors, Runs, Attempts, leases, and the outbox live in PostgreSQL with SKIP LOCKED coordination.

02 · Transport

NATS JetStream for dispatch

A bounded outbox publisher dispatches work via CRONO_DISPATCH with Attempt ID deduplication, draining safely after outages.

03 · Scheduling

Durable schedules & misfires

One-shot UTC and IANA-timezone cron schedules with explicit run_late, skip, and grace_period policies.

04 · Execution Pool

DB-isolated worker pools

Workers pull within Queue concurrency limits, renew leases over NATS control subjects, and hold zero database credentials.

05 · Observability

Separated retries & live visibility

Dispatch retries never consume Job attempts. Execution retries create new immutable Attempts with live output tails and /metrics.

Architecture

Clear boundaries across state, transport, and execution.

Authoritative SQL transactions JetStream WorkQueue dispatch (crono.dispatch.<queue_uuid>) Server-mediated lease, output, & presence control

API & Web UI

crono-server · crono-web

Axum HTTP API with an OpenAPI 3.1 contract, scoped Bearer auth, and a Leptos WASM web console.

Scheduler

Indexed cursors

Claims due Schedules, commits Runs, Attempts, and outbox rows together, and advances next_run_at.

PostgreSQL

Source of truth

Stores definitions, immutable Run snapshots, leases, outbox events, and audit history.

NATS JetStream

CRONO_DISPATCH

Queue-scoped WorkQueue streams for durable dispatch and worker control traffic.

Workers

crono-worker

Scalable Rust daemons running direct processes or shell scripts with bounded live output tails.
